# Ads (PR 2 of 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Banner ads for FREE users only, on the workout list and the workout screen. They load only after Google's UMP consent allows, never on the timer, and never for PRO. An "Ad privacy choices" row appears in ⚙ Settings when UMP requires one.

**Architecture:**
- **`ads/AdsController`** sequences tier → consent → `MobileAds.initialize` (spec §2.2's startup order) over two
  thin interfaces, `ConsentGateway` (UMP) and `AdsSdk` (MobileAds). Fakes test it.
- **`ads/AdMobRenderer`** implements the existing `AdRenderer`. It draws nothing until the controller is ready
  **and** its banner has loaded, so the slot stays zero-height until then.
- **`MonetisationModule`** binds the real pieces.

**Tech Stack:** Kotlin, Compose, Hilt, coroutines; Google Mobile Ads (`com.google.android.gms:play-services-ads`), UMP (`com.google.android.ump:user-messaging-platform`); Robolectric Compose tests.

**Spec:** `docs/superpowers/specs/2026-10-21-pro-and-ads-design.md` (rev 41) §2, §4 (`ad_privacy`), §5 and §7 PR 2.
**Depends on:** PR 1 (`docs/superpowers/plans/2026-10-21-pro-purchase.md`) merged, which provides `Entitlements` backed
by billing, `CurrentActivityProvider` and `ProStore`.

## Global Constraints

- **Placements:**
  - The only placements are `AdPlacement.ENTRY_LIST` and `AdPlacement.ENTRY_SCREEN`, in the Scaffold
    `bottomBar` (rev 18 §4).
  - No timer placement, no dialogs, no Entry Settings.
  - No interstitial, rewarded or app-open ads.
- **The banner:** one anchored adaptive banner per placement, each with its own ad unit ID. Until it has loaded,
  and after a failure, the slot is zero-height.
- **Pro:** never loads the ads SDK. Neither `MobileAds.initialize` nor UMP runs while the tier is PRO.
- **Startup order on FREE (§2.2):**
  1. tier known;
  2. `requestConsentInfoUpdate`, then the form if required;
  3. only if `canRequestAds()`: `MobileAds.initialize` (off the main thread), then banners request.
- **Debug builds always use Google's test IDs:**
  - app `ca-app-pub-3940256099942544~3347511713`;
  - adaptive banner unit `ca-app-pub-3940256099942544/9214589741`.
- **Release builds** take `-Prepkit.admobAppId`, `-Prepkit.adUnitList` and `-Prepkit.adUnitEntry` (or the same
  keys in `~/.gradle/gradle.properties`), falling back to the test IDs. A release build on test IDs logs a build
  warning.
- **Crash reporting:** UMP and ads errors go to `CrashReporter.log` with the error code only.
- **Consent and the crash switch are independent:** consent doesn't affect the crash/usage switch (rev 30) and
  vice versa.
- **Project rules** (as in PR 1's plan):
  - pure `domain/`;
  - all text from resources;
  - es / zh-rCN / hi via the l10n data file;
  - rgradle only;
  - `mitenko` identity, no attribution, one squashed commit.

## Review Focus

1. **The tier flips to PRO mid-sequence** (purchase finishes while the consent form is open): `ready` ends false,
   `initialize` is never called afterwards, and the slots compose nothing (Task 1).
2. **Consent denied or unavailable** (`canRequestAds() == false`, or the update errors offline): no initialize,
   `ready` stays false, the slots stay zero-height, no crash. The next foreground retries (Task 1).
3. **Return to the foreground after initialising:** `initialize` isn't called twice, and consent is updated again,
   as UMP recommends (Task 1).
4. **A banner that fails to load** (no fill, offline): the slot stays zero-height, with no gap above the bottom of
   the screen (Task 2).
5. **The privacy-options row** shows only when UMP says it's required **and** the tier is FREE. Tapping it opens
   the form on the current Activity, or does nothing when there's none (Task 3).

```kotlin
package com.mitenko.repkit.ads

import android.app.Activity

/** Google's UMP behind a testable face (spec rev 41 §2.2). [UmpConsentGateway] is the real one. */
interface ConsentGateway {
    /** requestConsentInfoUpdate; ok is false on an error (offline, misconfigured). */
    suspend fun update(activity: Activity): ConsentState
    /** loadAndShowConsentFormIfRequired; returns when the form is closed or wasn't needed. */
    suspend fun showFormIfRequired(activity: Activity)
    fun canRequestAds(): Boolean
    /** Reopens the form from Settings → Ad privacy choices. */
    fun showPrivacyOptions(activity: Activity)
}

data class ConsentState(val ok: Boolean, val privacyOptionsRequired: Boolean)

/** MobileAds.initialize behind a testable face. */
interface AdsSdk {
    suspend fun initialize()
}
```

```kotlin
package com.mitenko.repkit.ads

import com.mitenko.repkit.di.ApplicationScope
import com.mitenko.repkit.domain.CrashReporter
import com.mitenko.repkit.domain.Entitlements
import com.mitenko.repkit.domain.Tier
import com.mitenko.repkit.monetisation.CurrentActivityProvider
import com.mitenko.repkit.monetisation.ProStore
import kotlinx.coroutines.flow.first
import kotlinx.coroutines.CoroutineScope
import kotlinx.coroutines.flow.MutableStateFlow
import kotlinx.coroutines.flow.StateFlow
import kotlinx.coroutines.flow.asStateFlow
import kotlinx.coroutines.launch
import kotlinx.coroutines.sync.Mutex
import kotlinx.coroutines.sync.withLock
import javax.inject.Inject
import javax.inject.Singleton

/**
 * Spec rev 41 §2.2: on FREE, tier → consent → MobileAds.initialize, and only then [ready]. PRO never runs any of
 * it, and turning PRO at any step ends not ready.
 */
@Singleton
class AdsController @Inject constructor(
    private val entitlements: Entitlements,
    private val proStore: ProStore,
    private val consent: ConsentGateway,
    private val sdk: AdsSdk,
    private val activity: CurrentActivityProvider,
    private val crash: CrashReporter,
    @ApplicationScope private val scope: CoroutineScope,
) {
    private val _ready = MutableStateFlow(false)
    val ready: StateFlow<Boolean> = _ready.asStateFlow()
    private val _privacy = MutableStateFlow(false)
    val privacyOptionsRequired: StateFlow<Boolean> = _privacy.asStateFlow()

    private val lock = Mutex()
    private var initialized = false

    init {
        scope.launch {
            entitlements.tier.collect { tier ->
                if (tier == Tier.PRO) {
                    _ready.value = false
                    _privacy.value = false
                }
            }
        }
    }

    /** Called from MainActivity.onResume: (re)runs the sequence on FREE. */
    fun onForeground() {
        scope.launch { run() }
    }

    private fun free() = entitlements.tier.value == Tier.FREE

    private suspend fun run() = lock.withLock {
        // A Pro user reads FREE until the cached tier is loaded; never start consent before that (Review Focus 1).
        proStore.cacheLoaded.first { it }
        if (!free()) return@withLock
        val a = activity.get() ?: return@withLock
        val state = consent.update(a)
        if (!state.ok) {
            crash.log("ads: consent update failed")
            return@withLock
        }
        if (!free()) return@withLock
        _privacy.value = state.privacyOptionsRequired
        consent.showFormIfRequired(a)
        if (!free()) return@withLock
        if (!consent.canRequestAds()) return@withLock
        if (!initialized) {
            sdk.initialize()
            initialized = true
        }
        _ready.value = free()
    }

    fun showPrivacyOptions() {
        val a = activity.get() ?: return
        consent.showPrivacyOptions(a)
    }
}
```

  Test 6 checks for PRO after the form and **before** `canRequestAds`. That's why its expected calls are
  `[update, form]` with `inits == 0`.

```kotlin
package com.mitenko.repkit.ads

import android.app.Activity
import android.content.Context
import com.google.android.gms.ads.MobileAds
import com.google.android.ump.ConsentInformation
import com.google.android.ump.ConsentRequestParameters
import com.google.android.ump.UserMessagingPlatform
import dagger.hilt.android.qualifiers.ApplicationContext
import kotlinx.coroutines.Dispatchers
import kotlinx.coroutines.suspendCancellableCoroutine
import kotlinx.coroutines.withContext
import javax.inject.Inject
import javax.inject.Singleton
import kotlin.coroutines.resume

@Singleton
class UmpConsentGateway @Inject constructor(@ApplicationContext private val context: Context) : ConsentGateway {
    private val info: ConsentInformation by lazy { UserMessagingPlatform.getConsentInformation(context) }

    override suspend fun update(activity: Activity): ConsentState = suspendCancellableCoroutine { cont ->
        info.requestConsentInfoUpdate(
            activity, ConsentRequestParameters.Builder().build(),
            { cont.resume(ConsentState(ok = true, privacyOptionsRequired = info.privacyOptionsRequirementStatus == ConsentInformation.PrivacyOptionsRequirementStatus.REQUIRED)) },
            { cont.resume(ConsentState(ok = false, privacyOptionsRequired = false)) },
        )
    }

    override suspend fun showFormIfRequired(activity: Activity) = suspendCancellableCoroutine { cont ->
        UserMessagingPlatform.loadAndShowConsentFormIfRequired(activity) { cont.resume(Unit) }
    }

    override fun canRequestAds(): Boolean = info.canRequestAds()

    override fun showPrivacyOptions(activity: Activity) {
        UserMessagingPlatform.showPrivacyOptionsForm(activity) { }
    }
}

@Singleton
class MobileAdsSdk @Inject constructor(@ApplicationContext private val context: Context) : AdsSdk {
    override suspend fun initialize() = withContext(Dispatchers.IO) {
        suspendCancellableCoroutine { cont -> MobileAds.initialize(context) { cont.resume(Unit) } }
    }
}
```

```kotlin
package com.mitenko.repkit.ads

/** One AdView per screen (spec rev 41 §2.1): an anchored adaptive banner sized to the window width. */
fun interface BannerFactory {
    @Composable
    fun Banner(unitId: String, onLoaded: () -> Unit, onFailed: () -> Unit, modifier: Modifier)
}

object RealBanner : BannerFactory {
    @Composable
    override fun Banner(unitId: String, onLoaded: () -> Unit, onFailed: () -> Unit, modifier: Modifier) {
        val context = LocalContext.current
        val widthDp = LocalConfiguration.current.screenWidthDp
        val view = remember(unitId) {
            AdView(context).apply {
                adUnitId = unitId
                setAdSize(AdSize.getCurrentOrientationAnchoredAdaptiveBannerAdSize(context, widthDp))
                adListener = object : AdListener() {
                    override fun onAdLoaded() = onLoaded()
                    override fun onAdFailedToLoad(error: LoadAdError) = onFailed()
                }
                loadAd(AdRequest.Builder().build())
            }
        }
        DisposableEffect(view) { onDispose { view.destroy() } }
        AndroidView(factory = { view }, modifier = modifier)
    }
}

/**
 * Spec rev 41 §2.1–§2.2: draws nothing until [readyFlow] (consent and initialize done), then the banner, kept at
 * zero height until it has loaded, so nothing jumps and a failure leaves no gap.
 */
class AdMobRenderer(private val readyFlow: StateFlow<Boolean>, private val banner: BannerFactory = RealBanner) : AdRenderer {
    @Composable
    override fun Render(placement: AdPlacement, modifier: Modifier) {
        val ready by readyFlow.collectAsStateWithLifecycle()
        if (!ready) return
        var loaded by remember(placement) { mutableStateOf(false) }
        val unit = when (placement) {
            AdPlacement.ENTRY_LIST -> BuildConfig.AD_UNIT_LIST
            AdPlacement.ENTRY_SCREEN -> BuildConfig.AD_UNIT_ENTRY
        }
        banner.Banner(
            unitId = unit,
            onLoaded = { loaded = true },
            onFailed = { loaded = false },
            modifier = modifier.fillMaxWidth().then(if (loaded) Modifier.wrapContentHeight() else Modifier.height(0.dp)),
        )
    }
}
```
